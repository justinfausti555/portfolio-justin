# Gerador de Palavra-passe

Gerador local de palavras-passe aleatórias usando JavaScript e a API Web Crypto.

## Funcionalidades

- Escolher o tamanho
- Incluir maiúsculas, números e símbolos
- Indicador simples de força
- Copiar o resultado para a área de transferência

## Executar

Abra `index.html` no navegador.
