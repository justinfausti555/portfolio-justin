# Laboratório de Segurança

Pequena ferramenta local para estudar fundamentos de segurança em ambientes autorizados.

## Funcionalidades

- Análise básica de protocolo, domínio, porta e credenciais numa URL
- Geração de hash SHA-256 no navegador
- Codificação e descodificação Base64

A ferramenta não faz scans nem tenta explorar sistemas. Abra `index.html` no navegador.
