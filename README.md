# Portfolio de Justin Faustino

Portfolio pessoal em React, com uma experiência 3D e projetos práticos de desenvolvimento web.

## Projetos práticos

- [Minhas Tarefas](projects/tarefas-js): lista de tarefas com filtros e `localStorage`.
- [Gerador de Palavra-passe](projects/gerador-password): gerador local usando a API Web Crypto.
- [Rastreador de Despesas](projects/despesas-js): registo de despesas e cálculo de totais em kwanzas.
- [DevBoard](projects/devboard): quadro Kanban com pesquisa, criação e drag-and-drop.
- [Laboratório de Segurança](projects/lab-seguranca): análise local de URLs, SHA-256 e Base64.

## Executar o portfolio

```bash
npm install
npm run dev
```
